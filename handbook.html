type_map：元素索引的唯一权威

为什么这个元胞不需要冻结层

12 个原子全部保持 move = 1 1 1。理由有三条：

  • z 方向周期，两个界面首尾相接，没有真空也没有自由表面，没有需要锚住的体相层。
  • 全弛豫代价只有十几秒，冻结换来的机时节省没有意义。
  • 冻结 4 个原子等于删掉 1/3 自由度，可能把界面核心该弛豫的部分锁死，再把人为应变算进结果。
冻结的正当用途是大体系省自由度与真空 slab 的体相锚定。一旦真的加了约束，ABACUS 的 Largest gradient in force 只统计可动原子，判据就必须分栏报告 —— 详见口径备忘。

PROTOCOL

四条先钉死的口径

这四条不改变流程，但决定后面所有数字能不能互相比较。任何一条没定，能量与力的比较结论就不成立。

01 · MASK

冻结是省机时的手段，不是必需品

体系大、全弛豫太贵时才冻结底层：减少自由度换机时，同时给真空 slab 一个体相锚点。代价是人为减少自由度，并把冻结层上的人为应变算进结果。

本体系 12 原子、周期双界面、无真空，全弛豫的代价只有几秒，因此 fixed: 0，判据直接用全原子。一旦以后加了约束，就必须记住 ABACUS 的 Largest gradient in force 只统计可动原子。

02 · DTYPE

能量比较统一双精度

float32 的 machine epsilon 是 1.19e-7。在 ~10² eV 的总能上，最小可分辨步长约 1e-5 eV，而弛豫末段相邻帧的能量差常在 0.1–1 meV/atom 量级 —— 同一数量级，float32 分辨不了。

候选帧能量排序、误差表、分支能量比较：必须 float64。checkpoint 权重本身的 dtype 决定上限，把推理切成 float64 不能恢复已丢失的精度。文件往返也要查 dtype：.npy 存成 float32、.cif 只写 4–6 位小数、JSON 用 %.6g 写大数，都会毁掉精度。

03 · DISPERSION

色散口径一次定死

本算例标签用 vdw_method d3_0。DPA4 是局域描述符模型（截断 ~6 Å），长程 1/r⁶ 项在物理上无法被局域模型表示 —— 喂再多标签也学不出来。

因此：要么 ML 侧外挂同款色散，要么全程只用 DFT 的色散口径做最终判断。不允许把带回 DFT 色散的能量直接和裸 ML 能量比大小。

04 · ENERGY ZERO

能量零点先对齐再微调

DPA4-Air 的绝对能量与 DFT 的绝对能量差一个体系常数：本算例实测模型约 −57.3 eV、ABACUS 约 −5085.4 eV，差 −5027.9972 eV（9 帧标准差 0.00437 eV）。

微调的能量项直接吃绝对值，这个常数会把 loss 淹没 —— 实测后果是第一步就发散：验证集能量 RMSE 从 1e-2 跳到 4.19e+02，力误差从 0.009 涨到 1.97 eV/Å。

规则：微调前把所有标签改写成 E_dft − shift，帧间能量差完全不变。shift 取全部帧的平均偏移量，并记下它的标准差 —— 标准差若超过 0.05 eV，说明帧间差异已不是常数，单一 shift 不成立，先查能量随构型的漂移再谈微调。

CALIBRATION

标签精度标定

这一步回答一个独立问题：SCF 收敛限取多严，力的标签才算可靠。 它不属于训练监控，而是一次性标定 —— 在 12 原子体系上成本只有几分钟，没有理由跳过。

操作

  • 挑 2 个代表帧：一个高受力（早期）、一个低受力（末期）。
  • 每帧在 1e-4 / 1e-5 / 1e-6 三档下各做一次单点，其余参数完全不动。
  • 比较 12 个原子的逐分量力，算 MAE 与 RMSE —— 不要用最大偏差，单个原子的偶然离群会主导结论。
  • 同时记录 SCF 迭代数与墙钟时间，得到「阈值 → 力偏差 → 成本」三条曲线。

命令

foreach ($thr in "1.0e-4","1.0e-5","1.0e-6") {
  $d = "01_preflight\calib_$thr"
  Copy-Item -Recurse 01_preflight\scf $d
  (Get-Content "$d\INPUT") -replace 'scf_thr\s+\S+', "scf_thr $thr" |
    Set-Content "$d\INPUT"
  Push-Location $d; mpirun -np 8 abacus > scf.log; Pop-Location
}

相邻阈值之间，原子力的 MAE/RMSE 已到 1e-3 eV/Å 量级或更低，取较松的那个阈值作为生产口径。

受控 ML 预优化

固定晶胞，12 个原子全部可动。先跑 10–20 步，检查几何与能量后再决定是否延长。

操作

  • 02a 能力验证：先跑 10–20 步，检查后再继续。首轮只需要这一步。
  • 02b 生产采样：要跑主动学习时，把它当成“造候选池”而不是“把优化跑长”——多温度 / 多起点 / 多应变，每轮 ≥ 500 帧，规格与产物见 03B 步。

import numpy as np

from ase.optimize import BFGS
from ase.calculators.calculator import Calculator, all_changes
from deepmd.infer import DeepPot

class DPACalc(Calculator):
    implemented_properties = ["energy", "forces"]
    def __init__(self, model, type_map, **kw):
        super().__init__(**kw); self.pot = DeepPot(model); self.map = type_map
    def calculate(self, atoms=None, properties=("energy","forces"), system_changes=all_changes):

2. 分会审查：只验合法性，不重复训练

分会由 06 步训练（那也是它“再优化与多候选”的一部分）。 本节不重复这件事，只规定什么样的分会才能拿来打分。以下四条只要一条不满足，本轮 σ 全部作废：

合法性检查（逐条打勾）

  • 3 个 LoRA 模型，只有 training.seed 不同（例如 17 / 42 / 2026），其余全部相同。
  • base checkpoint 相同、数据划分相同、超参相同、LoRA 的 rank 与 alpha 相同。
  • 每个成员都过了 05B 的采纳门（留出误差确有改善）—— 分会里混进一个坏模型，σ 立刻失去含义。
  • 逐成员的 seed / rank / alpha / checkpoint SHA-256 已记录在 committee/ 下。
合法做法
3 个成员 = 同数据、同超参、不同训练随机种子。
三种“假分会”
① 同一个 checkpoint 复制三份（σ 恒为 0，会得出“模型很自信”的假结论）；② 只改几何起点跑的 3 条弛豫（那是多起点优化，测的是几何敏感性，不是模型分歧）；③ 用不同数据子集却不记录划分（σ 里混进了数据差异，无法归因）。

3. 打分：逐帧不确定度

指标

  • 逐原子力标准差：σi = 三个模型对同一个原子的力逐分量求标准差，再取范数。
  • 帧级：sigma_max = max_i σ_i、sigma_mean = mean_i σ_i。
  • 能量标准差：sigma_E = std(E) —— 必须先对齐能量零点（见 05B 的坑 5），否则 σE 会被那个 −5028 eV 的常数淹没。
  • 力向量夹角：同向偏差是系统偏差，反向抖动才是真不确定；夹角 > 60° 的行单独打 flag。

4. 分区阈值：低 / 中 / 高到底是多少

分会力标准差的分区（12 原子 LiF Σ3 口径）
区间σ_max (eV/Å)含义动作
低< 0.01模型一致，这一带已学会丢弃，不再送 DFT
中0.01 – 0.05模型分歧，有信息量送 04 打标签
高> 0.05模型崩溃或物理异常先诊断（重叠 / 爆炸 / 外推过远），不盲目标注

这两个数字不是拍的：

阈值依据

  • 0.01 eV/Å 约为本体系实测 ML-vs-DFT 力 MAE（0.002–0.009 eV/Å）的 1–5 倍 —— 低于它的分歧已经淹没在模型自身误差里，再算一帧也学不到东西。
  • 0.05 eV/Å 就是 07 的验收线本身 —— 分歧超过验收线的帧，模型自己都分不清该往哪走，标它之前应先排除几何异常。
  • 阈值随体系变：原子数上去、元素变多之后，用同一套流程的标定步（C）重新量一遍误差地板，再按同样的倍数取值。

5. 选帧：不确定度 × 多样性

只按 σ 排序会选出一堆几乎相同的帧（同一个盆地里反复抖）。必须叠加多样性约束：

选择规则（确定性，可复现）

  • ① 过滤：只保留中段帧。低段丢弃，高段先诊断。
  • ② 排序：按 sigma_max 降序取前 3k 帧（k = 本轮配额，6–10）。
  • ③ 贪心去重：score = sigma_max × exp(−d_min / 0.5)，其中 d_min 是该帧到已选帧的最小 RMSD（Å）；每选一帧更新一次。RMSD < 0.05 Å 的两帧合并，只留 σ 大的那帧。
  • ④ 强制配额：1–2 帧取 σ_max 最高（不看多样性，专挑最可能暴露偏差的）；1 帧取 d_min 最大（离已有训练集最远，防止整轮停在同一个盆地）。
  • ⑤ 分箱约束：界面帧占比 ≥ 50%，温度与应变分箱各至少 1 帧。任一约束不满足就回退一格重选。
第 ④ 条是这套流程与“按能量最低挑一个”的根本区别。按 ML 能量挑，你只会反复验证模型已经相信的那条路径；按分歧挑，才是在问模型“你哪里最不确定”。

STEP 06

再优化与多候选

用不同种子的 LoRA 模型做分会，按力偏差而非单一能量挑候选。

操作

  • 训 3 个 LoRA 模型：只有 training.seed 不同，数据划分、超参、base checkpoint 全同（组法与三种“假分会”见 03B 步）。
  • 对同一帧预测逐原子力，算模型间标准差 σF；这是主动学习的唯一不确定度信号。
  • 从原始结构与首轮候选终点分别启动第二轮优化，得到新候选。
  • 把 σF 分档，中段帧交给 03B 的选帧规则（不确定度 × 多样性）挑出送 DFT 的那几帧。
  • 记录新区域事件，必要时回到 03–05 再采样；轮次写进 al_rounds.csv。

力偏差怎么读

分档数值的来历见 03B 的“分区阈值”
模型间力标准差含义动作
低　< 0.01 eV/Å模型一致，已学会丢弃，不再送 DFT
中　0.01 – 0.05模型分歧，有信息量送 04 步打标签（由 03B 排序挑选）
高　> 0.05模型崩溃或物理异常先诊断，不盲目标注
候选选择原则
不能只按 ML 能量最低选一个。优先保留能量、受力、配位、界面距离和异常事件都合理的候选，交给 DFT 单点验收；同时务必保留 1–2 个力分歧最高的候选，它们最能暴露模型偏差。
停止条件
模型在新区域明显失效（力分歧普遍偏高 / 几何持续异常）→ 回到 03–05 补标签，不继续盲目优化。
低分歧不等于准确。多个模型可能共享同一套训练偏差，一起错。所以分歧只能用来“挑哪些帧去算 DFT”，不能用来“代替 DFT 下结论”。

出口条件（不满足不得进 07）

  • 池子与候选终点上逐帧的 σF（uncertainty.csv），以及低 / 中 / 高计数。

前置条件：分会门必须已通过

晶界能 γ_GB

只对验收结构计算性质。参考态必须与界面同口径，否则数字看着正常但错一个量级。

公式与代入

γ_GB = (E_GB - N * E_bulk/atom) / (2A)

E_GB        07 步验收结构的总能（同一 DFT 口径）
E_bulk/atom LiF 岩盐相单点总能 / 原子数
N           12
A           7.2202 A^2      -> 2A = 14.4404 A^2
分母 2      周期晶界模型有两个界面
判据
  • E_GB 与 E_bulk 用完全相同的 ecutwfc / scf_thr / 赝势 / 轨道 / kspacing
  • 两者都 SCF 真收敛
  • 报告 γ_GB 时同时给出 E_GB、E_bulk、N、A 四个原始量
报告边界
可以写「该晶界在当前 DFT 口径下的晶界能为 X J/m²」；不能仅凭一个静态 γ_GB 推出迁移率、离子电导或力学强度。
这个数暂时不能写进结论。元胞 a₃ = 14.145 Å、双界面，两个界面只隔 ≈7.07 Å，晶粒半区仅 ~3.5 Å 厚 —— 两个界面在强耦合。算出的 γ_GB 会被这种相互作用污染。要做这个数，得用 144 原子或 232 原子的大元胞，并做界面间距收敛。12 原子这一步的价值是把公式和参考态走通，不是取值。

第一，γ_GB。12 原子元胞里两个界面只隔 ≈7.07 Å、晶粒半区仅 ~3.5 Å，界面强耦合。算出的晶界能会被污染，不能当“LiF Σ3 晶界能”写进结论。要做这个数，得用 144 / 232 原子元胞并做间距收敛。
第二，微调幅度。LiF 是二元宽禁带离子晶体，OMat24 预训练势本就覆盖得好，可能几帧标签就收敛。这个结论不能外推到多元素、含过渡金属、磁性、非晶的体系 —— 那边覆盖弱得多，微调需求会大一个数量级。

口径备忘

这几个词在整站里都有严格含义，不要混用。混用它们，往往是数值没错、结论错。

主动学习 ≠ 微调
主动学习是采样策略（决定去算哪些 DFT）；微调是更新策略（拿到标签怎么改模型）。二者正交，标准做法是把微调放进每一轮闭环内部。
收敛 ≠ 程序结束
「程序正常结束、步数用尽」不等于 SCF 收敛。判据是最后一次 DRHO 达标，不是退出码。
冻结 ≠ 必需
冻结原子是为了在大体系里省自由度换机时、并给真空 slab 一个体相锚点。小周期体系全弛豫的代价更低，冻结只会凭空删掉自由度并把人为应变算进结果。
可动 ≠ 固定
一旦设了约束，ABACUS 的最大受力判据只统计可动原子；固定层带建模代价，其反力单独报告，不参与判据。用全原子最大值当判据会高估偏离倍数。
力偏差分区
会做分会时，模型间力标准差低表示已学会；中段表示有信息量，值得送 DFT；高段表示模型失效，先诊断再标注。
低分歧 ≠ 准确
多个模型可能共享同一套训练偏差一起错。分歧只能用来挑哪些帧去算 DFT，不能代替 DFT 下结论。
float32 的边界
力与几何优化到 0.05 eV/Å 用 float32 可接受（噪声约 1e-3 eV/Å）；但候选帧能量排序、误差表、分支能量比较必须 float64。
参考态纪律
任何差值量（晶界能、黏附功、分离功）都要求两端同泛函、同截断、同 k 点、同赝势轨道。参考未收敛时，只允许“参考偏差完全相同”的组内比较。
