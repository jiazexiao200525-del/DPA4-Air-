DECISION GATES

决策门 · LiF Σ3 (111) 晶界

任何一个门不通过，就停在当前阶段。这样可以把失败定位到模型、数据、电子收敛或结构，而不是最后才发现整条链条无法解释。

模型门

通过：checkpoint 可加载、映射正确、单帧力有限、原子顺序与 STRU 一致。

回退：修环境、接口、元素顺序或单位。

标签门

通过：SCF 收敛、能量/力有限、参数口径一致、原子数与元素顺序逐帧一致。

回退：修 DFT 输入，或把帧移入 failed_frames。

结构门

通过：最大受力分量 ≤ 0.05 eV/Å（本体系全可动，用全部原子；若设了约束则用可动原子），且无异常短接触。

回退：补标签、再优化，或做少量 DFT 几何细化。

协议与精度门

通过：色散口径已确认、checkpoint provenance 与 dtype 已查明、SCF 阈值经原子力 MAE/RMSE 标定、能量比较在 float64 下完成。

回退：补做口径核对、查模型信息、重跑阈值标定。

分会门

通过：已出示：① 3 成员分会台账（仅 training.seed 不同、各过采纳门）；② al_rounds.csv 至少一行；③ 本轮 σ 的低/中/高计数；④ “送 / 不送新标签”的书面理由。

回退：回 05B 重训分会，或回 03B 补打分与选帧决策。

为什么是这五道门

门拦住的是哪一类错误典型症状
模型门工具链错误（接口、映射、单位）力全都对但顺序错位、能量数量级不对
标签门数值错误（未收敛、参数漂移）同一个结构两次算不一样
结构门物理错误（几何不合理）受力达标但有 1.2 Å 的 Li–F 接触
协议与精度门可比性错误（口径不一致）两个数都“合理”但不能相减
分会门过程性错误（没做主动学习判据就下结论）「模型挺好，直接验收」但拿不出 σ 与轮次记录
顺序有意义。门是从“便宜且基础”排到“昂贵且综合”的：模型门几秒钟就能过，协议门要几分钟，结构门要一帧 DFT，分会门则要求先花 ¥1.5 训出三个种子 —— 它是唯一一道“主动花钱”的门，因为“该不该继续加标签”这个问题，只能用分会回答。

分会门：本版新增的强制环节

前三道门管“数字对不对”，第四道管“数字能不能比”，第五道管“你有没有真的做过主动学习判据”。 它的存在是为了堵住一条捷径：训练一个模型 → 直接进 07 → 偶然通过 → 声称闭环完成。

通过条件（四项缺一不可）
  • committee/ 下 3 个成员 checkpoint + 各自 seed / rank / alpha / SHA-256
  • 每个成员都过了 05B 采纳门（留出误差确有改善）
  • al_rounds.csv 至少一行：池大小 / 中段帧数 / 送 DFT 帧数 / 花费 / 留出 MAE
  • selected.json 或等价记录：本轮选了哪几帧、为什么；若一帧不选，写明“无中段帧”的证据
不通过怎么办
缺成员台账 → 回 05B 重训；缺 σ 分布 → 回 03B；σ 显示确有中段帧却没送标签 → 不允许进 07，先补齐 04 → 05 → 05B。
“必然执行”指的是判据，不是标签。分会门强制的是打分 + 决策 + 留证；如果 σ 显示池子里没有中段帧，那么“本轮不需要新标签”就是正确结论 —— 但这份证据必须留下。反过来，明知有中段帧却跳过 04 直接验收，是最典型的假闭环。
