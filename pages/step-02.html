STEP 02

受控 ML 预优化

固定晶胞，12 个原子全部可动。先跑 10–20 步，检查几何与能量后再决定是否延长。

操作

  • 02a 能力验证：先跑 10–20 步，检查后再继续。首轮只需要这一步。
  • 02b 生产采样：要跑主动学习时，把它当成“造候选池”而不是“把优化跑长”——多温度 / 多起点 / 多应变，每轮 ≥ 500 帧，规格与产物见 03B 步。
  • 限制单步最大位移，初始可从约 0.02–0.05 Å 的保守范围试起。
  • 每一步保存坐标、ML 总能量、逐原子力、最大位移、优化状态。
  • 收敛阈值不得低于推理精度地板；要压到 1e-2 eV/Å 以下就切 float64。

命令（ASE + DPA4-Air，最小可用形式）

import numpy as np
from ase import Atoms
from ase.optimize import BFGS
from ase.calculators.calculator import Calculator, all_changes
from deepmd.infer import DeepPot

class DPACalc(Calculator):
    implemented_properties = ["energy", "forces"]
    def __init__(self, model, type_map, **kw):
        super().__init__(**kw); self.pot = DeepPot(model); self.map = type_map
    def calculate(self, atoms=None, properties=("energy","forces"), system_changes=all_changes):
        super().calculate(atoms, properties, system_changes)
        at = np.array([self.map.index(s) for s in atoms.get_chemical_symbols()])
        e, f, _ = self.pot.eval(atoms.get_positions()[None],
                                atoms.get_cell().array[None], at[None], atomic=False)
        self.results["energy"] = float(e[0][0]); self.results["forces"] = f[0]

atoms = Atoms("Li6F6", positions=<12x3>, cell=<3x3>, pbc=True)
atoms.calc = DPACalc("DPA4-Air-OMat24-v20260805.pt", ["Li","F"])
BFGS(atoms, logfile="02_ml_round00/opt.log",
     trajectory="02_ml_round00/trajectory.traj").run(fmax=0.10, steps=20)

每段结束后检查

检查项阈值 / 形态超标怎么办
温度稳定性（AIMD 时）目标温度 ± 50 K先查 dt 与 smearing
单步最大位移无突增（> 0.5 Å 的帧标记为高风险）保留异常帧，不延长轨迹
Li–F 最短距离< 1.6 Å 视为异常短接触诊断为初始建模问题
局部配位轨迹中基本保持，无界面“消失”界面坍塌 → 停止
ML 最大受力单调下降或稳定波动能量爆炸 → 停止
停止条件
能量爆炸、位移突增、键断裂或骨架坍塌 → 保留异常帧，但不要延长轨迹。
为什么会失效
ML 势最容易在训练集没覆盖的局部环境处失效，而错误通常先出现在优化中间帧 —— 这就是为什么每一步都要存轨迹，而不是只留终点。
“跑完 20 步”不等于“优化完成”。首轮的目标只是证明模型能读结构、能产生有限力、能给出可用的中间构型 —— 不是为了收敛。收敛留给 07 步的 DFT 验收去判断。若要进入主动学习循环，02b 造出的候选池就是 03B 的输入，池子大小直接决定后面几轮的上限。
