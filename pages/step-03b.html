STEP 03B · ACTIVE LEARNING

主动学习采样

03 是“从一条已知轨迹里挑帧”，03B 是“用模型自己的分歧决定下一帧该算哪里”。首轮没有分会可用，第二轮起由这一步接管选帧。

0. 这一步在流程里的位置

上游是谁 / 下游是谁

  • 前置条件一：05B 已产出一个通过采纳门的模型。没有模型就没有分会，σ 无从谈起。
  • 前置条件二：06 已训练好 3 成员分会并算出逐帧 σ。分会是 06 的产物，03B 只是消费者 —— 本步不重复训练，只审查分会是否合法（见第 2 节）。
  • 下游固定是 04：产出的 selection_manifest.json 与 03 步格式相同，04 步不需要区分帧是从哪一步来的，但轮次必须写进 manifest。
  • 出口只有一个：循环靠 03B 的停止条件跳出，跳出后进 07。σ 不能代替 DFT 下结论。
首轮（round 0，事件驱动）
  00 → 01 → 02a → 03 → 04 → 05 → 05B → 06
                                        └─ 06 训练 3 成员分会，算出逐帧 σ（σ 是 06 的输出）

第二轮起（round ≥ 1，分会驱动）—— 03B 就在这个位置
  ① 03B    按 σ × 多样性选出 6–10 帧
  ② 04     打标签（SCF 单点，不做离子步）
  ③ 05     合并进数据集，重新划分训练/验证（防相邻帧泄漏）
  ④ 05B'   用合并后的数据重训 3 个种子（谁过采纳门谁当生产模型）
  ⑤ 06     重算 σ，重新分低 / 中 / 高
  ⑥ 回到 ①，除非停止条件已满足

停止条件满足后（唯一的出口）
  07 DFT 受力验收 → 08 γ_GB
为什么首轮不能进 03B：只有一个模型时不存在“模型间分歧”，硬做就是把同一份权重复制三份，σ 恒为 0，会得出“模型很自信”的假结论。首轮用事件驱动（03）不是退让，而是没有分会时唯一诚实的做法。

什么时候提前触发 03B（不必等一整轮跑完）

  • 06 里出现中段分歧的帧 —— 那是信息量最大的位置，直接送 04 打标签。
  • 07 验收未过，且残余力集中在界面原子 —— 需要界面的新覆盖，不是继续磨应变。
  • 要把模型用到训练集之外：新温度、新应变、点缺陷、更大晶胞。

1. 候选池：这一步的燃料

分会只能从你交给它的池子里挑。池子不够大，分会再准也只能在原有几帧里打转 —— 首轮最大的局限就在这里：只有一条短轨迹的 9 帧，模型分歧必然很小，所以首轮用事件驱动（03）：那不是退让，而是没有分会时唯一诚实的做法。

2. 分会审查：只验合法性，不重复训练

分会由 06 步训练（那也是它“再优化与多候选”的一部分）。 本节不重复这件事，只规定什么样的分会才能拿来打分。以下四条只要一条不满足，本轮 σ 全部作废：

合法性检查（逐条打勾）

  • 3 个 LoRA 模型，只有 training.seed 不同（例如 17 / 42 / 2026），其余全部相同。
  • base checkpoint 相同、数据划分相同、超参相同、LoRA 的 rank 与 alpha 相同。
  • 每个成员都过了 05B 的采纳门（留出误差确有改善）—— 分会里混进一个坏模型，σ 立刻失去含义。
  • 逐成员的 seed / rank / alpha / checkpoint SHA-256 已记录在 committee/ 下。
合法做法
3 个成员 = 同数据、同超参、不同训练随机种子。
三种“假分会”
① 同一个 checkpoint 复制三份（σ 恒为 0，会得出“模型很自信”的假结论）；② 只改几何起点跑的 3 条弛豫（那是多起点优化，测的是几何敏感性，不是模型分歧）；③ 用不同数据子集却不记录划分（σ 里混进了数据差异，无法归因）。
成本口径：3 × 400 步 LoRA 在单卡 4090 上约 ¥1.5，是本步的主要开销；推理打分反而是零头 —— 12 原子约 0.03 s/帧，3 个模型 × 500 帧约 1 分钟。这笔训练费和 05B 是同一笔：05B 需要至少一个种子，练三个就等于顺手把分会做好了。

3. 打分：逐帧不确定度

指标

  • 逐原子力标准差：σi = 三个模型对同一个原子的力逐分量求标准差，再取范数。
  • 帧级：sigma_max = max_i σ_i、sigma_mean = mean_i σ_i。
  • 能量标准差：sigma_E = std(E) —— 必须先对齐能量零点（见 05B 的坑 5），否则 σE 会被那个 −5028 eV 的常数淹没。
  • 力向量夹角：同向偏差是系统偏差，反向抖动才是真不确定；夹角 > 60° 的行单独打 flag。

打分脚本（骨架，模型列表换成自己的 3 个成员）

import itertools, numpy as np
from deepmd.infer import DeepPot

MODELS = ["committee/m1.pt", "committee/m2.pt", "committee/m3.pt"]
pots = [DeepPot(m) for m in MODELS]
tmap = pots[0].get_type_map()          # 三个成员必须同一张 type_map

for frame in frames:                   # 每帧: coords(n,3), cell(3,3), species
    idx = np.array([[tmap.index(s) for s in frame.species]])
    F = []
    for p in pots:
        out = p.eval(frame.coords[None], frame.cell.reshape(1, 9), idx, atomic=True)
        F.append(np.array(out[1]).reshape(-1, 3))
    F = np.array(F)                    # (3, natoms, 3)
    sigma_i = np.linalg.norm(F.std(axis=0), axis=1)   # 逐原子
    row = dict(frame_id=frame.id,
               sigma_max=float(sigma_i.max()),
               sigma_mean=float(sigma_i.mean()),
               sigma_E=float(np.std([p.eval(..., atomic=False)[0][0][0] for p in pots])))
    rows.append(row)

4. 分区阈值：低 / 中 / 高到底是多少

分会力标准差的分区（12 原子 LiF Σ3 口径）
区间σ_max (eV/Å)含义动作
低< 0.01模型一致，这一带已学会丢弃，不再送 DFT
中0.01 – 0.05模型分歧，有信息量送 04 打标签
高> 0.05模型崩溃或物理异常先诊断（重叠 / 爆炸 / 外推过远），不盲目标注

这两个数字不是拍的：

阈值依据

  • 0.01 eV/Å 约为本体系实测 ML-vs-DFT 力 MAE（0.002–0.009 eV/Å）的 1–5 倍 —— 低于它的分歧已经淹没在模型自身误差里，再算一帧也学不到东西。
  • 0.05 eV/Å 就是 07 的验收线本身 —— 分歧超过验收线的帧，模型自己都分不清该往哪走，标它之前应先排除几何异常。
  • 阈值随体系变：原子数上去、元素变多之后，用同一套流程的标定步（C）重新量一遍误差地板，再按同样的倍数取值。

5. 选帧：不确定度 × 多样性

只按 σ 排序会选出一堆几乎相同的帧（同一个盆地里反复抖）。必须叠加多样性约束：

选择规则（确定性，可复现）

  • ① 过滤：只保留中段帧。低段丢弃，高段先诊断。
  • ② 排序：按 sigma_max 降序取前 3k 帧（k = 本轮配额，6–10）。
  • ③ 贪心去重：score = sigma_max × exp(−d_min / 0.5)，其中 d_min 是该帧到已选帧的最小 RMSD（Å）；每选一帧更新一次。RMSD < 0.05 Å 的两帧合并，只留 σ 大的那帧。
  • ④ 强制配额：1–2 帧取 σ_max 最高（不看多样性，专挑最可能暴露偏差的）；1 帧取 d_min 最大（离已有训练集最远，防止整轮停在同一个盆地）。
  • ⑤ 分箱约束：界面帧占比 ≥ 50%，温度与应变分箱各至少 1 帧。任一约束不满足就回退一格重选。
第 ④ 条是这套流程与“按能量最低挑一个”的根本区别。按 ML 能量挑，你只会反复验证模型已经相信的那条路径；按分歧挑，才是在问模型“你哪里最不确定”。

7. 与 03、06 的分工

两步不要混用
03（首轮 / 事件驱动）03B（第二轮起 / 分会驱动）
判据几何事件：位移、配位、能量/力突变模型间力标准差 σF
候选池一条短轨迹的 9–20 帧MD 多温多应变 ≥ 500 帧
谁决定人按配额表挑分会分数 + 多样性约束，人只审配额
为什么这样分工首轮只有 1 个模型，没有 σ 可用已有可采纳的模型，σ 才开始有意义
进 04 的条件
入选帧都有 sigma_max、分箱归属、一行可读理由三项；且配额与分箱约束都满足。
不许进 04 的情况
① 用同一 checkpoint 复制的“分会”；② 只按 ML 能量最低挑的帧；③ σ_max > 0.05 却未做几何诊断的帧；④ 与已标注帧 RMSD < 0.05 Å 的重复帧。
低分歧不等于准确：三个模型可能共享同一套训练偏差一起错。所以 σ 只能用来决定“算哪一帧”，永远不能替代 07 的 DFT 验收。
